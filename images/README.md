# images/

The figures the repository README shows.

- `synthetic_*.png` are the five method figures, run on the bundled
  synthetic data. `bash images/regenerate.sh` from the repository root
  rebuilds them. They are committed because GitHub shows README images
  only from committed files, and `output/` is not tracked.
- `figure5_with_sections.png` is the article's Figure 5 with the
  repository's section numbers added; `data-shape.png` is the
  input-data schematic.
