# 03 · Identifying Local Types: Latent Class Analysis

Recover local types, recurring profiles of co-occurring criteria, with `poLCA`, then measure whether the types cut across or map onto the ascriptive statuses (Cramér's V, drawn as mosaics), the most direct assessment of organizational consolidation. The script saves the run of record that methods/04 and 05 use.

- **Run on your own data:** `recover-local-types.R` (calls functions in the repo-root `R_functions/`).
